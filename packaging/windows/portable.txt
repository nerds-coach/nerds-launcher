NERDS Launcher portable mode

While this file sits next to artcraft-launcher.exe, NERDS Launcher keeps its settings, its
download cache and its record of installed apps in the NERDSLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move NERDS Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\NERDS Launcher) instead.
If NERDSLauncherData can't be written (for example on a read-only drive), NERDS Launcher says
so and uses %APPDATA%\NERDS Launcher instead.
